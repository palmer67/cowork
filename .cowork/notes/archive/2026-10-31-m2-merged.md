## 用法

```bash
cowork task add --title "补登录校验" --touches src/auth/login.ts --done-when "npm test"
git add .cowork/tasks && git commit -m "task: 补登录校验"
cowork task ready t-xxxxxx

# 车道里
cowork next && cowork task start t-xxxxxx
# …改代码、提交…
cowork task report-done t-xxxxxx
cowork task done t-xxxxxx          # 跑 trunk 上的验证命令
cowork task confirm-merge t-xxxxxx --commit <sha> --manual --reason "人工确认"
```
